# CallDesk 1.0.1 发布版本 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将所有 CallDesk 构建配置的发布版本设为 1.0.1，构建号设为 2。

**Architecture:** 版本值仅由 Xcode 工程构建设置提供。应用与测试目标的 Debug、Release 配置使用相同值，避免生成的 Info.plist 与设置页显示不一致。

**Tech Stack:** Xcode project build settings, xcodebuild。

---

### Task 1: 更新与验证发布配置

**Files:**
- Modify: `CallDesk.xcodeproj/project.pbxproj`
- Create: `docs/superpowers/specs/2026-08-25-release-1.0.1-design.md`
- Create: `docs/superpowers/plans/2026-08-25-release-1.0.1.md`

- [ ] **Step 1: 验证旧配置未达到目标**

Run: `rg -n 'MARKETING_VERSION = 1\\.0;|CURRENT_PROJECT_VERSION = 1;' CallDesk.xcodeproj/project.pbxproj`

Expected: 输出六组旧版本字段。

- [ ] **Step 2: 更新所有配置**

将每个 `MARKETING_VERSION = 1.0;` 替换为 `MARKETING_VERSION = 1.0.1;`，将每个 `CURRENT_PROJECT_VERSION = 1;` 替换为 `CURRENT_PROJECT_VERSION = 2;`。

- [ ] **Step 3: 验证目标配置**

Run: `test "$(rg --no-filename 'MARKETING_VERSION = 1.0.1;' CallDesk.xcodeproj/project.pbxproj | wc -l | tr -d ' ')" = 6 && test "$(rg --no-filename 'CURRENT_PROJECT_VERSION = 2;' CallDesk.xcodeproj/project.pbxproj | wc -l | tr -d ' ')" = 6`

Expected: exit 0。

- [ ] **Step 4: 构建验证**

Run: `xcodebuild build -project CallDesk.xcodeproj -scheme CallDesk -destination 'generic/platform=iOS Simulator'`

Expected: `** BUILD SUCCEEDED **`。
