Overview

CallDesk is a lightweight queue calling application designed for fast, reliable, and intuitive operation.

It helps staff quickly call customers, participants, or visitors with a single tap while providing clear visual status management and voice broadcasting.

The application works completely offline and requires no server or network connection.

项目简介

CallDesk 是一款轻量级、离线优先的叫号应用，专为需要快速、高效叫号的场景设计。

用户只需轻点一次，即可完成语音叫号，同时通过清晰的状态颜色管理整个叫号流程。

应用无需联网即可完整运行，所有数据默认保存在本地。
